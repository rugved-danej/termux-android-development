# Termux Android Development (`tadev`)

Termux Android Development (`tadev`) is a standalone, production-grade CLI tool and orchestration suite designed to turn any Android device running Termux into an autonomous, high-performance Android application compilation workstation.

It configures the complete toolchain required to compile, assemble, and sign modern Android APKs and App Bundles (AABs) natively on ARM64, ARM (32-bit), x86_64, and x86 devices without requiring root access, PRoot containers, or a separate PC.

---

## The Vision: Native Mobile App Compilation

Historically, mobile developers attempting to compile Android apps inside Termux faced severe architectural barriers:

1. AAPT2 Binary Incompatibility: Gradle pulls Maven-packaged AAPT2 binaries compiled strictly for desktop `x86_64` Linux or macOS, resulting in immediate `exec format error` crashes on ARM64 mobile hardware.
2. Android Execution Restrictions: Modern Android versions (Android 10 through 15+) enforce `noexec` mount options across shared external storage (`/sdcard`, `/storage/emulated/0`), prohibiting binary execution.
3. Android Low Memory Killer (LMK): The Android kernel aggressively terminates heavy background processes when free RAM drops. Unguarded Gradle daemons attempting to allocate 4GB+ heap get terminated via `SIGKILL`.
4. Java Bytecode Version Conflicts: Newer host JDK versions (e.g., Java 25) can trigger `Unsupported class file major version` errors inside older Android Gradle Plugin (AGP) and Kotlin compiler pipelines.
5. Missing Linux Bootstrapping: Standard Android SDK command-line tools rely on `/bin/bash` and desktop Linux paths that do not exist under Android's bionic libc environment.

`tadev` completely resolves every one of these problems automatically.

---

## Core Capabilities

- Native ARM64 AAPT2 Override: Automatically discovers or compiles Termux's native `aapt2` and registers it in `~/.gradle/gradle.properties` (`android.aapt2FromMaven=false`), forcing Gradle to use native ARM64 binaries.
- Dynamic RAM Auto-Tuning: Reads `/proc/meminfo` at runtime to calculate optimal Gradle heap size (`-Xmx`) and garbage collection parameters (`-XX:+UseG1GC`), preventing Android LMK kills.
- Multi-Profile Java Engine: Exclusively uses official Termux stable packages (`openjdk-21`, `openjdk-25`, `openjdk-17`). OpenJDK 21 LTS is set as the recommended default for maximum stability and 300MB storage savings.
- Zero External Dependencies: Non-blocking browser opener built directly on base Android Activity Manager intents (`am start --user 0`) and Termux bootstrap tools (`termux-open-url`). Zero dependency on `com.termux.api` or `termux-api`.
- Keyboard-Driven TUI Dashboard: Terminal User Interface supporting keyboard navigation (`[Up]`/`[Down]`, `[Enter]`, `[Tab]`, `[Esc]`, and vim-style `j`/`k`).
- Comprehensive Clean Engine: Granular removal tool allowing developers to reclaim gigabytes of storage by clearing Gradle build caches, daemon logs, or SDK temporary files.
- Native Shell Tab-Completion: Built-in tab-completion generators for Bash, Zsh, and Fish.

## Cross-Platform Termux Architecture Support

`tadev` is engineered exclusively for Termux on Android and supports all official Termux architectures:

- `aarch64` / `arm64`: Modern Android phones and tablets (Android 7.0 - 15+) - Primary Tier-1 Target
- `armv7l` / `arm`: Legacy 32-bit Android devices - Supported
- `x86_64` / `amd64`: Intel/AMD Chromebooks, WSA, Emulators running Termux - Fully Supported
- `i686` / `386`: 32-bit x86 emulators - Supported
