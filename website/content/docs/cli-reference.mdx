# CLI Command Reference

This document provides a comprehensive reference for all commands, flags, and arguments supported by `tadev`.

---

## Command Summary

- `tadev` (aliases: `menu`, `tui`, `dashboard`): Launch interactive terminal UI dashboard
- `tadev install` (alias: `setup`): Install complete Android development environment
- `tadev java` (alias: `jdk`): Manage OpenJDK profiles (switch, list, test)
- `tadev sdk`: Inspect installed platforms or install extra SDK packages
- `tadev ndk`: Manage Android NDK native toolchains and shebangs
- `tadev clean` (aliases: `clear`, `purge-cache`): Purge build caches, daemon logs, and reclaim storage
- `tadev completion` (alias: `autocomplete`): Generate or install shell tab-completion
- `tadev doctor` (aliases: `status`, `health`): Comprehensive diagnostic check of all components
- `tadev config` (alias: `cfg`): Inspect or initialize configuration (~/.config/tadev/config.yml)
- `tadev update` (alias: `upgrade`): Download and apply all available updates
- `tadev check` (alias: `check-updates`): Check for updates across SDK, repos, and CLI
- `tadev self-update` (alias: `self-upgrade`): In-place upgrade of tadev binary from GitHub releases
- `tadev uninstall` (aliases: `remove`, `desetup`): Granular uninstallation chooser or complete removal
- `tadev version` (aliases: `-v`, `--version`): Display version, author, and device architecture
- `tadev help` (aliases: `-h`, `--help`): Display command-line usage guide

---

## Detailed Command Documentation

### `tadev` (Dashboard)
Runs the interactive full-terminal user interface.
```bash
tadev
```
Navigate using arrow keys or `j`/`k`, select with `Enter`, toggle descriptions with `Ctrl+D`, and exit with `Esc`.

---

### `tadev install` / `setup`
Installs packages, Android Command-Line Tools, SDK platforms, AAPT2 override, and shell configuration.
```bash
tadev install [options]
```

Options:
- `--force`: Force re-download and re-installation of command-line tools even if already present.
- `--java <profile>`: Specify Java profile headlessly (e.g., `21`, `25+21`, `25+17`, `21+17`, `25`, `17`).

---

### `tadev java`
Manages OpenJDK runtimes and compiler profiles.
```bash
tadev java <subcommand> [options]
```

Subcommands:
- `tadev java switch [profile]`: Switch active Java profile interactively or directly by ID.
- `tadev java list`: Display configured profile, active host directory, toolchain paths, and installed runtimes.
- `tadev java test`: Run compilation and verification test across `java`, `javac`, `gradle`, and `apksigner`.

---

### `tadev sdk`
Manages Android SDK platform packages and build tools.
```bash
tadev sdk <subcommand> [args]
```

Subcommands:
- `tadev sdk list`: List all installed SDK platforms and build-tools versions.
- `tadev sdk install <package>`: Install a specific package from Google repository (e.g. `platforms;android-34`).

---

### `tadev ndk`
Manages Android Native Development Kit (NDK) toolchains for C/C++ compilation.
```bash
tadev ndk <subcommand>
```

Subcommands:
- `tadev ndk status`: Display active NDK path, version, and toolchain status.
- `tadev ndk install`: Install recommended LTS Android NDK toolchain and automatically patch binary shebangs.
- `tadev ndk list`: List all installed NDK versions.

---

### `tadev clean`
Reclaims device storage space by purging temporary caches and logs.
```bash
tadev clean [target]
```

Targets:
- `tadev clean`: Purges Gradle caches and daemon logs.
- `tadev clean gradle`: Purges `~/.gradle/caches` and daemon logs.
- `tadev clean sdk`: Cleans temporary SDK download archives and extraction caches.
- `tadev clean all`: Purges all temporary build artifacts across both Gradle and SDK.

---

### `tadev completion`
Installs or generates native shell tab-completion scripts.
```bash
tadev completion <action> [shell]
```

Actions:
- `tadev completion install`: Automatically detects active shell (`bash`, `zsh`, `fish`) and installs completion script.
- `tadev completion bash`: Outputs Bash completion script to stdout.
- `tadev completion zsh`: Outputs Zsh completion script to stdout.
- `tadev completion fish`: Outputs Fish completion script to stdout.

---

### `tadev doctor`
Runs automated diagnostic health checks on every system dependency, returning actionable remediation steps for any failures.
```bash
tadev doctor
```

---

### `tadev config`
Inspects or customizes configuration settings (`~/.config/tadev/config.yml`).
```bash
tadev config [action]
```

Actions:
- `tadev config show`: Prints active configuration and file path.
- `tadev config init`: Initializes a fresh, well-commented configuration file.
- `tadev config reset`: Resets configuration back to defaults.
- `tadev config path`: Prints the absolute file path of the configuration file.

---

### `tadev self-update`
Upgrades the standalone `tadev` CLI binary in-place to the latest GitHub release.
```bash
tadev self-update [--force]
```

---

### `tadev uninstall`
Performs granular or complete uninstallation of installed development tools.
```bash
tadev uninstall [flags]
```

Flags:
- (no flags): Launches an interactive checkbox menu allowing you to pick exactly which components to delete.
- `--all`: Purges everything (SDK, JDKs, Termux packages, configuration, and self-removes binaries).
- `--self`: Self-removes `tadev` and `termux-android-dev` binary executables only.
- `--packages`: Purges installed development packages (`openjdk-21`, `openjdk-25`, `gradle`, `aapt2`).
- `--sdk-only`: Deletes only the Android SDK directory (`~/.android/sdk`).
- `-y`, `--yes`: Skips confirmation prompts.
