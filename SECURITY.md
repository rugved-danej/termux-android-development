# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0   | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability in `tadev`, please report it responsibly:

1. **Do not disclose the vulnerability publicly** in GitHub Issues or pull requests.
2. Open a private security advisory on GitHub under the **Security** tab of the repository, or contact the maintainer directly.
3. Include details of the vulnerability, steps to reproduce, and impact.
4. You will receive an acknowledgment within 48 hours and updates as a patch is developed and verified.
